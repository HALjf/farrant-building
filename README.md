# Farrant Building website

Static HTML/CSS/JavaScript starter site for **Farrant Building**.

## Edit the content

- Main page copy: `index.html`
- Colours/layout: `styles.css`
- Mobile menu/animations: `script.js`
- Logo and images: `assets/`

The main brand colour is `#aa4a44` and the charcoal is `#222222`.

## Replace placeholder images

Replace the SVG files in `assets/` or update the image paths in `index.html`. Keep meaningful `alt` text for real project photos.

## Local preview

You can double-click `index.html` to open it in a browser. For the closest match to GitHub Pages, use a local web server if you already have one.

## GitHub Pages

1. Create a new public GitHub repository, e.g. `farrant-building`.
2. Upload all files in this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then save.
6. Under **Custom domain**, enter `farrantbuilding.co.uk` and save.
7. Configure DNS at GoDaddy according to GitHub's current Pages documentation.
8. Once DNS resolves, enable **Enforce HTTPS** in GitHub Pages settings.

The included `CNAME` file already contains `farrantbuilding.co.uk`.
